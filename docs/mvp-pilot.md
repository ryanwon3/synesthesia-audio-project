scene without Spotify or the Windows companion. It uses the experimental 3D

## Live Spotify pairing — saved for later user testing

The Release Windows companion is currently open on this computer with the exact
hosted origin configured and legacy enrichment disabled. Normalized live frames
are designed to travel only over the local loopback connection, not to Vercel.

When ready for user testing:

1. Keep the Windows companion and desktop Spotify open.
2. In the companion, select **New pairing code**, then **Copy code**.
3. On the hosted page, select **Connect Windows companion** and paste the code.
4. Each code works once and expires within five minutes. Browser credentials stay
   in memory; reloading/reopening may require pairing again.
5. If the browser asks to connect to the local companion, review its normal local
   network permission. Do not disable browser security or bypass it manually.

For a quiet visual preview, use the synthetic button instead. Never paste pairing
codes, personal profile JSON, API keys or captured audio into support messages.

Current launch configuration belongs only to the running companion process. It
does not persist in Windows settings. Opening the executable normally after
closing it will require the exact hosted-origin configuration again. A convenient
safe restart/launcher remains the next approved pilot usability task for Claude.
