## Decisions and tradeoffs

- Local source groundwork proceeds after capture/isolation/profile-source checks,
  not full manual foundation acceptance. Cost: later live checks may require
  revisions; no publishing/default-palette gate can be skipped.
- Inline TDD reuses the isolated worktree and PowerShell/apply-patch ledger
  adaptation without automatic commits/evidence cleanup. Cost: scoped uncommitted
  changes, rather than commit ranges, are the review record.
- Existing approved design remains; production preset selection waits for Task 4.
  Cost: playback may revise parameters and no preset control is visible yet.
- Identity caps are title 256, artist 128, ID 128 ASCII alphanumeric; normalized
  matching is Unicode/case/whitespace only. Cost: unusual identities are rejected,
  never guessed or assigned to the user.
- Square-root normalized band energy is display sensitivity, not a DSP change;
  colors stay with their existing bands. Cost: listening must tune sensitivity.
- Explicit mapping history-reset/optional manual-theme APIs support lifecycle/UI.
  Cost: narrow API growth, compatible with existing callers.
- Optional seeded RNG and 1–512 capacity guards make bounds testable. Cost:
  out-of-range custom capacities are refused; production defaults are unchanged.
- Scene tests traverse six meshes rather than assume root hierarchy. Additional
  resource-owner tests cover rollback/teardown. Cost: structure/cleanup checks
  cannot replace real appearance or GPU acceptance.
- Constructors own partial rollback; fallback does not force context loss.
  Cost: actual same-canvas GPU fallback still needs a browser check.
- Only the development-preview slice of Task 4 is implemented. Cost: production
  calibration/motion/resume remains unfinished.
- Composed RED proved nonfinite legacy values/delta could poison state; bounded
  guards prevent that. Cost: invalid numbers become defaults instead of NaN,
  with ordinary timing and DSP/protocol unchanged.
- Browser infrastructure failure is unverified acceptance, not permission to
  change drive security. Cost: undiscovered visual/GPU issues can remain.
